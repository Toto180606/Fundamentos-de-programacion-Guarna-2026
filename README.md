# Fundamentos-de-programacion-Guarna-2026

Este repositorio va a contener todos los ejercicios obligatorios, como tambien algunos ejercicios de las guias, modelos de parciales, resoluciones de los mismos.
Los temas que encontraran son incluyen en python (manejo de archivos y datos ):

1. Algoritmo de apareo (merge):
   De qué trata: Juntar dos archivos de texto (como el de la Eurocopa y Copa América) que ya vienen ordenados por un campo clave (ej. el día), en un tercer archivo único que     mantenga ese orden.
2. Corte de Control (Simple y Doble Nivel)
  De qué trata: Procesar un archivo secuencial ordenado por una o más categorías (como el de las notas semanales/actividades o el de los cursos/comisiones) para mostrar         subtotales cada vez que esa categoría cambia.
  La regla de oro: Clavar las variables del "registro anterior" afuera del bucle, comparar línea por línea, y acordarte de meter los print de vaciado abajo de todo cuando       termina el archivo para que no te quede colgado el último bloque.
3. Estructuras de Datos y Diccionarios
  De qué trata: Recorrer un archivo para agrupar estadísticas en un diccionario usando una clave única (como el nombre del país o del curso) y acumulando listas de datos        (como   [Ganados, Empatados, Perdidos] o los niveles educativos [PRI, SEC, UNI]).
4. Ordenamiento de Diccionarios y Filtrado
  De qué trata: Pasar un diccionario a una lista de tuplas con list(diccionario.items()) para poder ordenarlo de mayor a menor (o viceversa) usando el método .sort(key=lambda   item: ...) apuntando al valor que pide el enunciado, aplicando filtros como if ganados > 0.

En lenguaje c (Algoritmos y estructuras fundamentales):}

1. Búsqueda Binaria
  De qué trata: Encontrar la posición de un valor dentro de un array de enteros que ya está ordenado.
2. Recursividad en Arreglos
  De qué trata: Resolver un problema (como sumar los elementos en posiciones pares de un vector) llamando a la misma función a sí misma con un tamaño cada vez más chico (n     -1 o n - 2).
3. Algoritmo de Ordenamiento: Burbuja (Bubble Sort)
  De qué trata: Comparar pares de vecinos de izquierda a derecha. Si el de la izquierda es mayor, se intercambian (swap).
4. Algoritmo de Ordenamiento: Inserción (Insertion Sort)
  De qué trata: Dividir mentalmente el array en una parte izquierda ordenada (que arranca con un solo elemento) y una derecha desordenada. Se toma un elemento nuevo y se lo   arrastra hacia atrás, haciendo espacio (corriendo cartas) hasta meterlo en su lugar correcto.
